# 已移出 V5 回归的测试

本目录保留独立功能、旧选股政策及旧评分类反馈的测试源码，供查阅或专项排查。文件使用 `.mjs`，不使用 `.test.mjs` 命名，也不放在 `test/` 中，避免进入自动测试发现。

范围包括旧分钟采样回测与历史导入、AI 冷启动/研究/赛马/策略家族、评分统计证据、成本校准、独立 `dragon-risk-v1`、数据管理与运维告警。`*-obsolete.mjs` 是从混合文件移出的独立旧用例；`fixtures/` 冻结其原有合成输入。

`npm test`、`npm run test:v5` 和 CI 仅运行 [V5 回归清单](../scripts/run-v5-regression.mjs)。归档测试未纳入当前回归验收，不应批量加回清单。V5 所需的共享规则用例已在当前政策下保留或改写。
