# V5 回归范围

当前回归以 `signal-ranking-v5` 为范围，包括它使用的共享评分、分类、买点、费用、风险退出及账本能力。执行规则 `intraday-entry-v1`、做 T 质量规则等有各自版本号，仍属于 V5 执行链路。

```bash
npm test
npm run test:v5
npm run test:v5 -- --list
```

前两个命令使用同一份显式清单，CI 沿用 `npm test`。`--list` 只打印范围。清单与 `test/*.test.mjs` 必须一致；新增、缺失或重复登记的文件会使入口报错，新增用例应先核对范围再登记。

| 范围                     | 覆盖内容                                                                            |
| ------------------------ | ----------------------------------------------------------------------------------- |
| 评分、分类与买点         | 分类权重、精确排序、涨停/炸板/EOD 候选、六类买点、观察分级与资格门槛                |
| 行情与冻结输入           | 行情日期、候选价格、昨日字段、日线复权、竞价终态与因果性                            |
| 执行、持仓与账本         | 盘中触发、T+1、现金/容量/费用、退出与降级、做 T、重启续单、并发、周期归档和导出核验 |
| 影子观察、复盘与严格回放 | 候选/进度/成交查询、V5 执行反馈、历史重构、整段缺证据阻断及构建可加载性             |

共享手工计划 fixture 显式冻结 V5 选股政策及摘要。旧版本只在升级至 V5、拒绝非 V5 执行方式或识别政策冒充等 V5 边界场景中出现；不再独立运行 v1–v4 的排序与收益比较。

无关用例已移至 [归档目录](../legacy-tests/README.md)，包括独立 `dragon-risk-v1`、旧分钟回测、AI 研究赛马、旧评分反馈、数据管理及运维专项测试。归档文件不参与默认测试发现，也不计入 V5 通过数量。应用原有功能和历史兼容实现保留。

回归使用隔离数据库和合成输入，不改动生产账户；通过只表示规则及链路按预期运行，不代表真实行情表现。
