## 目录约定

```text
docs/
  README.md                         文档统一入口
  windows.md                        Windows 使用指南
  paper-trading.md                  当前模拟交易与核验说明
  design/
    ai-strategy-walk-forward.md      AI 改进与前瞻验证设计
    operations-alerting.md           P1 主动告警与运维可靠性
    historical-cold-start.md         P2 历史冷启动与研究回测
    multi-strategy-tournament.md     P2 多策略并行模拟、赛马与晋级
    experiments/
      benchmark-strategy-kernel.mjs  多账本纯交易内核合成探测
```

- 新设计方案归入 `design/`，文件名使用小写英文与连字符。
- 设计文档注明状态：待实施、实施中、已实施或已废弃，并记录设计依据的代码提交。
- 文档新增、移动或状态变化时同步更新本索引；实施完成后同步更新受影响的使用指南。
- 版本与修改历史使用 Git 管理，不另存多份带日期或“最终版”的副本。
- 文档仅使用示例或脱敏数据，不提交密钥、账户数据库、个人账户导出或认证信息。
