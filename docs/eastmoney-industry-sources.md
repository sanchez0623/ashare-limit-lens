# 东财行业接口核对

核对日期：2026-10-24，北京时间。股票范围：本项目已发布名册中的沪深主板与创业板，4,606 只，包含 ST。

F10 报表同时包含多种行业字段，不能看到“行业”就直接替代：

| 300750 宁德时代 | 电池        | 电力设备-电池-锂电池         | 电气设备-电源设备-储能设备         |

| 601112 振石股份 | 玻璃玻纤    | 建筑材料-玻璃玻纤-玻纤制造   | 基础化工-合成纤维及树脂-其他纤维   |

完整 A 股 F10 报表使用 `SECURITY_TYPE_CODE=058001001` 筛选，返回 8,370 行、17 页、8,370 个唯一 `SECUCODE`；报告包含历史记录，因此仍须和当前名册精确匹配。按代码与交易所匹配本项目 4,606 只后，无缺股，**第二层与原生 `f100` 的差异为 0**。实现只读取 `BOARD_NAME_LEVEL`，从未请求或使用 `EM2016` 作为更新值。

东方财富发布的[分级行业说明](https://caifuhao.eastmoney.com/news/1669048590)说明了当前一、二、三级行业结构。本项目采用第二层的依据还包括上面的实际全量字段对照，不只依靠名称推断。

## 行情原值继续保留

另取 2026-10-23 的真实涨停池：82 只中，75 只属于本项目名册范围。75 只中有 57 只 `hybk` 与原生 `f100` 字面相同，其余 18 只为显示缩写或罗马层级后缀差异，例如：

- 汽车零部 → 汽车零部件。
- 炼化及贸 → 炼化及贸易。
- 其他电子 → 其他电子Ⅱ。
- 家电零部 → 家电零部件Ⅱ。

程序没有据此规范化或改写行情原值。现有有效 `hybk` 仍优先，只有缺失时才使用已发布东财映射；本次更新不修改历史评分、交易计划、账本或评分口径。申万研究分类继续独立。

## 发布约束

- 原生批量接口精确校验每批请求集合、声明数量、返回数量、代码去重、市场及字段。若某新股的行业值明确为 `null` 或缺失标记，则单独计为未覆盖；整个批次丢失股票或漏掉 `f100` 字段则失败。
- F10 完整读取所有声明页，要求总数与页数固定、每页数量正确、证券标识唯一；随后要求目标名册全部匹配，当前行业路径必须符合三层格式。范围外的旧股票不会追加到名册。
- 仅连接中断、超时等网络故障允许切换到 F10，并从完整数据集重新开始；部分原生结果不与备用结果拼接。HTTP 429、403 和格式、覆盖校验失败不触发换源。
- 持久化实际 `source`、`emIndustrySource/emIndustryField`；F10 保存原始 `emIndustryPath`。备用启用原因写入任务与快照的 `warnings`，页面显示实际生效接口。
- 沿用暂存、短事务发布、取消检查、所有权检查和中断恢复；任何校验失败都保留上一份有效快照。未初始化独立名册的旧安装继续兼容原分页链路，失败时提示先更新名册。

## 接入验收

在独立临时数据库和真实浏览器上点击“更新东财行业”，实际 worker 完成原生批量请求并发布 **4,606 只、128 个行业、覆盖率 100%**，界面显示原生接口来源。关闭并重开页面可恢复任务，重复提交复用同一任务，页面无脚本错误，窄屏无横向溢出。

另模拟原生接口连接中断，真实请求 F10 全部分页并通过同一发布流程写入独立内存数据库：4,606 只全部成功，与原生结果的行业差异为 **0**，实际来源及备用原因均持久化。正式库只用于读取验收名册和已有研究映射，未用于发布；临时验收目录已清理。浏览器验收的行情接口使用空样本，行业接口为真实网络请求。
