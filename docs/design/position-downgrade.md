# 持仓降级的冻结与兼容口径

新评分快照显式携带 `downgradeRulesVersion: 1`，由该快照生成的计划携带相同版本和完整 `downgrades` 声明（无降级时为空数组）。计划执行、实时会话、零轮询结算及核验重放使用同一规则。声明的代码、原类别、新类别、原因与顺序均须由冻结输入重算一致，普通策略和程序策略都检查。

原始信号保存在不可修改的 `strategy_signal_snapshots` 中；展示归档重新计算不会改变冻结输入。仅修改计划并重算摘要，或删除版本和声明，均不能绕过核验。

历史快照未标记版本时保持原有行为，包含 `market.brokenRows` 也不会启用降级。不得给历史快照补写新版本。此前开发分支生成的“含降级声明但无规则版本”实验计划会被拒绝，须用新版评分快照重新冻结并重新开展实验；不能将这类未版本化结果当作新版证据延续。

## 完整板块均值

触发条件 2 只读取信号快照中以下可选输入，均值口径为当日全部板块成分股的算术平均涨幅（百分数，含持仓股）：

```json
{
  "sectorPerformance": {
    "date": "2026-10-15",
    "source": "完整板块行情来源标识",
    "complete": true,
    "sectors": [
      {
        "name": "测试行业",
        "memberCount": 101,
        "observedCount": 101,
        "averageChange": 0.4940594059
      }
    ]
  }
}
```

日期必须与信号日相同，来源非空，板块记录唯一，成分数为大于 1 的整数，覆盖数等于成分数，均值为有限数值。该输入随原始信号摘要冻结，不读取执行日或后来补齐的板块数据。

当前涨停池不能提供完整板块均值。未接入完整板块行情时，条件 2 跳过；禁止用涨停池均值或中位数替代。条件 1（更高连板）、条件 3（炸板未回封）、条件 4（高换手滞涨）仍按各自可用数据独立判断。
