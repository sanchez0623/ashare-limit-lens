# 龙头风险预算政策 dragon-risk-v1

新政策共用行情、费用、成本求解和唯一真实账本，但新仓、加仓、做 T 和退出不读取旧策略、风控、六因子权重、三档情绪敞口及分类退出参数。初始数值为工程假设，不是收益验证结论。

## 配置

常用页面展示八项账户风险与四个操作开关；六买点及三个高级参数折叠展示，共 **11 个数值、10 个开关**。

| 分组       | 字段                                      | 默认值             |
| ---------- | ----------------------------------------- | ------------------ |
| risk       | entryRisk / portfolioRisk                 | 0.005 / 0.02       |
| risk       | stockWeight / sectorWeight / grossWeight  | 0.15 / 0.30 / 0.50 |
| risk       | maxPositions                              | 4                  |
| risk       | dailyLoss / drawdown                      | 0.02 / 0.08        |
| operations | profitAdd / lossAdd / tForward / tReverse | 全部 true          |
| buyPoints  | 六个既有买点 type                         | 全部 true          |
| advanced   | stopLoss / tFraction / tSpread            | 0.04 / 0.10 / 0.02 |

完整对象携带 `version: "dragon-risk-v1"`。共享注册表定义类型、范围、单位、编辑权限和生效范围，随状态接口返回。页面折叠表逐项显示设定值、当前冻结计划的实际权限、限制原因及待生效计划。缺字段、未知字段、非有限值、错误类型、单笔风险超过组合风险、单股超过板块或板块超过总敞口均拒绝。人工修改可一次提交全部合法风险、开关和高级参数，不受最多两项或分组提交限制；AI 候选仍最多调整两个高级参数，不能修改账户风险和开关。

人工设置直接排队到下一份尚未冻结的计划，显示“人工指定 · 未验证”，不会自动获得研究通过资格。已有持仓周期的 P₀、R₀、保护位、减仓阶段与持有时钟不重置，已开始的 T 保留第一腿和目标价差。配置来源、验证方式及替代版本随不可变配置、计划和导出记录冻结。

人工配置生效后，可点击“发起研究验证”。系统另存相同参数为独立研究候选，沿配置血缘选择修改前的参数为对照；没有旧参数时使用固定初始配置。当前主账户继续运行，研究通过前保持未验证，不因发起验证而改写账本。验证入口可重入，不反复创建同一活动候选；新保存的配置须先在后续计划生效。

基础行为检查通过后，常驻执行器自动为原配置登记当前执行版本，保留版本血缘，不再要求重新手动保存。首次整体切换仍须用户申请；已启用账户的新版本在安全计划边界生效。升级前尚未执行的旧指纹计划保存为修订，再冻结新版本计划；已执行会话不回写。其他活动研究占用窗口时等待；当前龙头研究因执行版本变化失效，保留样本、报告和预算，不能沿用旧报告声称新版本通过。

活动研究锁定配置时，页面提供“终止当前研究并保存”，提交时绑定正在展示的研究类型和编号。支持龙头研究、旧实验和赛马批次：作废本轮研究、停止对应影子账户并释放该锁，与新配置保存原子提交。原始报告、样本使用和月度预算不删除；账户或研究并发变化时整次操作拒绝，不误释放新锁。

## 固定交易模板

- 上升允许已启用操作；高潮预算为 70% 且禁止亏损补仓；退潮禁止新增并逐步降至 20%；冰点退出；数据不足仅保留有效行情支持的保护。改善需两份不同的有效市场快照，恶化立即收紧。
- 买点沿用 `intraday-entry-v1` 的六类形态与窗口：已冻结历史、已知分类和涨停基因、三亿元流动性、板块分至少 55、连续报价及真实增量成交量。排序为买点优先级、信号日成交额、代码；盘前最多 100、全日最多 200 只。
- 新仓按退出距离、费用和计划风险计算数量，再受现金、单股、板块、总仓位、组合风险和共享容量约束。待成交买单和 T 买回共同预留，实际成交或撤销前不释放。跳空、跌停和 T+1 仍可能导致实际损失超过估算。
- 盈利 0.5R₀ 至 1R₀前，有新买点可加仓一次，最多初仓 50%；亏损 0.5R₀—0.75R₀并有低吸确认可补仓一次，最多 25%。每次新增风险最多为新仓预算一半。建仓当日不加仓，同股每日一次，与新 T 互斥，部分成交不重复计次。
- 1R₀、2R₀各减战略建仓量的 30%，余量跟踪最高已观察价回撤 1R₀；首档提高保护位至含费加权成本。减仓基数含加仓、不含 T，首档冻结后禁止加仓。打板最多 4 个结算日，炸板/首阴 3 日，其余 2 日。
- 正向 T 以前收回落 2% 后企稳触发；反向 T 以上涨 2% 后两份报价不再上涨触发。09:35—14:45前启动，14:50起尝试第二腿，14:57后不补造成交。第一腿以实际成交量为准，余量不追加；两腿不能使用同一报价，实际可成交量须覆盖双边费用和预计成本。
- 正向 T 锁定可卖旧股与临时买入预算，反向 T 预留恢复资金、敞口与风险；连续两轮净亏损暂停三日。保护退出和战略减仓优先，其次 T 恢复，再新仓/加仓，最后启动 T。风险中断的 T 不标完成收益。

## 影子验证与整体切换

首次手动启用为 `DRAFT → READY → DRAINING → ACTIVE`：保存配置后检查配置完整性、当前执行源码指纹及基础行为，全部通过即可申请切换，不要求先取得真实整日报告。基础行为检查覆盖配置隔离、市场确认、新仓、两类加仓、双向 T、重复帧与 T+1；不写入实际账户，也不作为真实交易日或收益优势证据。执行版本过期或基础检查失败时仍暂停启用，重新保存配置不会自动切换主账户。

独立影子观察继续采集，完整真实交易日覆盖、竞价/市场输入、原始计划和行情摘要、账本重放及 1.5/2 倍成本压力结果作为运行诊断。缺少报告或覆盖不足不阻止首次手动启用，也不标记为验证通过。如果当前配置及执行版本的报告已发现账本重放、财务核对或成本压力下资金核对失败，仍须排查后启用。未先完成真实环境验收，可能在正式模拟运行中才发现采集、时段或结算问题；缺行情停止新增、资金及仓位预算、T+1 和财务核对仍由执行器独立执行。AI 候选和主动提交验证的人工候选走 `OBSERVING → READY`，必须完成完整研究和真实技术报告。

影子账户和计划可在交易日 **09:30 前**准备，09:26、09:29:59 冻结的计划可以执行；09:30 起禁止补造当天计划。候选日线补齐与新政策/V5盘中计划的实际执行检查使用相同截止时间。盘前常驻准备按轮询周期重试，避免五分钟间隔跨过开盘截止线。仅存在新政策影子账户时也启动联合行情采集。页面区分已登记待准备、已冻结待开盘、等待行情执行、正在执行、消费中断和等待核验。

真实交易日影子核验从北京时间 **17:00** 开始；15:05 的常规盘后更新不生成影子通过或失败报告，常驻流程在 17:00 后独立重试。完整性仍要求 09:30—11:30、13:00—14:55 连续行情、竞价和市场输入、账本重放及成本压力检查。已错过的计划或行情不能靠更改时间补成完整验证日；早于17:00直接调用核验器也只返回等待状态。

申请切换核验统一研究窗口锁。结清期间取消旧新仓、加仓和未启动 T，仅处理已有仓位退出与已开始 T 的必要第二腿。空仓、无未完成退出/恢复、旧会话结束，且处于盘后或次日 09:30 前时，原子切换并冻结新计划。尚未执行的旧未来计划保留修订记录，历史成交不重写。

保留现金、历史收益与绩效峰值，不借切换重置回撤。新配置缺失、损坏或执行版本变化且尚未衔接时，禁止新增，不回退旧默认值。结清期间源码变化，自动登记原配置的新执行版本，期间仍禁止旧体系新增。

日内暂停次日解除。回撤熔断须在结清实际仓位和订单、会话关闭后人工开启新运行风险周期；只重建运行风险参考，历史绩效峰值保留。

## 高级模板研究

AI 仅调整 stopLoss、tFraction、tSpread，每次最多两个组，步长分别为 0.005、0.02、0.005。数据不足不调用模型；模型只接收 60 日训练输入，不接触 20 日封存测试输入。

候选、日期和输入清单先冻结，与研究窗口锁、月度名额及测试日期原子提交。历史及新的 30 日前瞻均比较候选、匹配父模板和固定初始模板，并重跑 1/1.5/2 倍成本。三组前瞻账户的逐日实际成交、会话、净值及总账还须与原始帧重放完全一致。候选须至少三笔成交，净收益至少高对照 0.1 个百分点，回撤不超过对照加 0.5 个百分点且不超过用户上限。测试及前瞻日期一次性使用，重启不能跳过冻结测试。缺覆盖、参数改变、政策混用或摘要变化均不能晋级。

高级模板研究通过后仍核验真实技术报告；自动模式排队到下份计划，手动模式需批准。人工直接采用与研究验证是独立路径，人工保存不会放宽 AI 晋级或主动研究的条件。旧策略 AI、冷启动和赛马晋级入口不能修改新账户。

## API 与核验

- `GET /api/paper` 增加 `dragon`；`GET /api/paper/dragon` 单独返回状态、配置、报告和研究进度。
- `POST /api/paper/settings` 接受 `{ "dragonConfig": <完整对象> }`；终止当前研究并保存时增加 `cancelResearch: { ownerType, ownerId }`，与资金、费用等基础账户设置分开提交。来源由服务端确定，客户端不能伪造 AI 或研究资格。
- `POST /api/paper/dragon/preview` 接受 `{ "config": <完整对象>, "phase": "rising" }`，不保存。
- `POST /api/paper/dragon/activate` 申请结清切换，或批准已验证模板。
- `POST /api/paper/dragon/validate` 对已生效人工配置发起独立研究验证，不改写当前参数或账本。
- `POST /api/paper/dragon/resume` 在结清后恢复回撤熔断。

新账户拒绝旧 strategyParams、riskLimits、selectionPolicyVersion、entryExecutionMode 写入；费用、资金和基准保留。旧配置只读查看。页面分别展示 T 配对价差与账户总盈亏，避免重复相加。

追加迁移 0027/0028/0031 保存配置版本、独立计划绑定、技术报告、研究清单及带摘要的配置来源。导出包括新配置及绑定，核验器重放新旧会话与切换事件；删除政策标记、篡改配置来源、验证方式或行情均拒绝。

严格历史回放同样按当前交易政策分派。新政策冻结自己的配置、固定候选来源权重和买点门槛，使用相同的新仓、加仓、T 及退出执行器；旧回放保留其原始配置和旧内核。历史数据缺少新政策需要的市场状态或其他必要证据时阻断整段收益，不把旧评分设置作为新政策默认值。历史回放仍不能替代真实影子验证。

## 使用步骤

1. 构建并重启本机服务；本机数据库初始化时自动追加迁移，既有持仓及历史记录保留。
2. 在“模拟交易 → 龙头交易 · 风险预算配置”检查默认值，保存新配置。当前执行版本及基础行为检查通过后显示“可启用”；保存本身不切换主账户。
3. 申请结清旧仓。结清状态跨重启保留；满足空仓、无未完成操作和时间要求后整体切换。旧配置转为只读历史。
4. 保持常驻交易执行器运行，09:30 前确认计划已准备。可另外查看完整交易日 17:00 后的影子覆盖、实际成交、重放和压力诊断；诊断缺失或覆盖不足不阻止首次手动启用，已发现的账本或资金核对异常仍须先排查。
5. 新政策运行期间，人工参数保存后用于下一份未冻结计划，显示未验证。需要研究结论时，配置生效后点击“发起研究验证”；AI 仍先研究再晋级。已有持仓的初始风险和未完成 T 的首腿基准继续保留。

`legacy-tests/dragon-risk.mjs` 保留整日行情与报告的合成测试，仅在隔离内存数据库中运行，不代表真实生产验证。该独立政策已移出 V5 默认回归；`npm test` 的范围见 [V5 回归说明](../v5-regression.md)。真实运行诊断及高级模板的影子验证仍须真实交易日数据，不能使用合成测试替代。

归档的 `legacy-tests/dragon-flexibility.mjs` 覆盖人工全参数保存、未验证标记、冻结计划及持仓/T 基准、自动版本登记与幂等、旧计划修订保护、主动研究验证、三类研究取消、事件链及预算留存、账户 CAS 冲突和 API 来源隔离。
