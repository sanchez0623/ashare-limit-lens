# 市场观察室

状态：已实施于 `codex/market-observatory` 开发分支，以改版开始时的工作区为基线。

纸感界面将现有功能组织为今日观察、深入研究、模拟执行和复盘档案。系统菜单保留数据管理、运维告警、研究设置及策略赛马。评分、冻结计划、账本和交易规则使用原业务实现。

## 导航和日期

地址使用 `#/today`、`#/research/industry`、`#/research/themes`、`#/research/stocks`、`#/execution/live|plan|ledger|config`、`#/archive/review|replay`、`#/system/data|alerts|settings|strategies`。查询参数保存研究日期、分类、搜索、行业、题材、连板和排序。旧页面 hash 和交易配置锚点继续映射到对应入口。

研究日期首次从现有 latest-date API 获取；显式链接和用户手动选择优先。模拟执行中的账户行情日、结算日与研究日期独立显示。前进后退恢复筛选，详情使用原生 dialog，关闭后回到原列表。

## 图形和导出

连板结构每层对应一个实际高度，正面宽度按该高度个股数量线性绘制。行业拼图按当前研究分类聚合，面积对应家数，色深对应评分；较小行业合并为明确标注的“其他”，完整数据保留在列表。申万研究分组沿用原有口径，不改变交易评分。

市场切片只接受已有盘后归档的冻结 analysis，缺失指标显示“—”。导出为 1200 × 1500 PNG，仅包含日期、公开市场结构、指标、板块和来源。SVG 通过现有 CSP 已允许的 data URL 栅格化，不扩展资源权限。

## 开发与核验

`frontend/observatory-model.js` 提供地址编解码和数据图形；`observatory.js` 管理界面组合及切片导出；`observatory.css` 在构建时拼入原样式。现有执行面板移动原 DOM 节点，保留表单和业务事件。账户模块仅初始化一次，沿用单个 15 秒刷新循环，浏览器后台时停止刷新。

运行 `npm run test:ui` 验证地址恢复、日期边界、图形可访问性和归档导出边界；`npm test` 保持原 V5 回归范围。浏览器检查覆盖板块→个股→冻结计划、前进后退、执行四个子页、归档切片导出，以及桌面和手机布局。
