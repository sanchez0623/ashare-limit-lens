# 三维市场环境、买点统计与独立对照

状态：已实施；固定工程初值，用户启用、尚未验证。收益有效性仍需前瞻积累，不授予自动采用资格。

## 执行语义

新计划绑定 `market-environment-v1`、`dragon-adaptive-risk-v3`。原V1/V2算法独立保留，旧计划按其冻结版本重放。旧历史无事前三维证据时保持缺失，不根据后来结果补造。

强度沿用连续算法及实际可得的昨日涨停溢价，分界50、70分；方向优先用5分钟变化，缺少5分钟时用1分钟，超过±2分才标记改善/恶化。缺少连续样本时方向未知。页面读取执行器已提交的环境，不另算一套。

前一日涨停名单、连板高度、收盘基准价及可得时间随盘前计划冻结。普通样本至少5只，高位（≥3板）至少3只，有效报价覆盖率至少80%。缺基准价的成员保留在分母，报价不可用；高位样本数量不足单列不适用。除权等造成昨收基准不一致时，报价不计为有效，避免虚构受损。

`F=max(当前炸板数/(涨停数+炸板数), 昨日涨停跌≥3%比例, 昨日高位跌≥5%比例)`，取有效比例的最大值。部分比例缺失时整体分组标记未知，但已知的高风险比例仍立即限制预算；不使用缺失数据来放宽。旧有更严上限最多保留3分钟，过期后使用当前有效比例；全部比例缺失才完全降级为原预算。

新增风险的市场系数取 `min(原连续市场系数, max(0.25,1-F))`，不再重复相乘。恶化立即收紧，恢复需3份独立证据持续60秒，并沿用每步0.2上限。缺数据保留最后有效上限至多3分钟，然后明确降级为原预算。没有新增全局预热闸门。报价15秒、市场90秒和20秒增量容量规则保持原值。

脆弱性仅约束建仓、加仓及T第一腿。已有持仓保护使用原系数；T第二腿通过 `T_RECOVERY` 路径恢复。原账户费用、硬风险上限、T+1和撮合不放宽。

## 机会与周期

每账户、股票、交易日、买点仅记录首次结构触发；未开启买点也保存触发及禁用原因。另冻结首次实际建仓成交的环境。预算、现金、盘口和容量决策与账户CAS在同一事务落库，证据失败时成交一同回滚。

部分成交、加仓和T腿不增加独立样本；收益按原优先级实际选择的首次建仓买点归属。分别展示买点×强度、方向、脆弱性，脆弱性固定分为低于1/3、1/3至2/3、达到2/3。首次触发环境用于机会和成交率，首次实际入场环境用于完整周期表现，两者不互相回填。

完整OPEN至清仓周期才计扣费净损益与净R，未清仓单列。至少30个完整周期及20个不同入场日才形成描述性区间。按入场交易日聚类，并以5日循环区块重采样10000次，保留同日相关性。区间不代表盈利概率，不自动改权重或启停买点。入场后MAE/MFE只使用实际收到的价格，未覆盖完整持仓路径时保持未知；不使用事后日高低价。

## 固定对照窗口

原版V2、新版V3、取消市场择时三个独立影子账户与主账户共用期初账本、候选、行业版本、联合行情帧和费用；每组现金、持仓、消费游标、成交容量独立。新版影子与主账户逐帧环境、逐笔成交和结算不一致时，比较标记缺证据，主账户继续独立执行。

无市场择时组移除市场系数与市场确认的择时影响；行业、个股、行情有效性、T+1、资金及硬风控照常执行。

清单在第一帧以前冻结模型、配置、版本和30个交易日窗口。真实指数交易日期决定窗口；缺日仍占用窗口，不能延长、删亏损日或重跑找好结果。已完成或已观测后失效的窗口不会自动重开。只有尚无任何主/影子观测的失效准备可被新准备替代，并保留原清单。

盘后17:00起由独立评分进程计算统计和报告，不在交易轮询中回放。完整窗口统一执行1/1.5/2倍成本压力，复用实际执行内核，核对1倍回放与真实影子结果。采用共同交易日区块与六个预登记比较的Bonferroni校正（族错误率0.05）。缺证据时报告INCONCLUSIVE，不伪造零收益压力结果。报告包括净收益、回撤、平均收盘资金利用率、费用及被过滤机会在对照账本中的实际成交和完整周期结果。

## 数据、版本及接口

迁移0040新增政策、帧级环境、机会、实验清单和不可覆盖报告。原始报价绑定来源时间；提交环境另绑定收到时间、帧序号、原观测/计划/费用/政策摘要。迟到修订只可用于收到后的决策，后来清仓不能提前进入统计。已发布报告冻结输入前缀；追加未来帧不改过去结果。读取会核验报告、机会与来源引用，计算时另完整核验原行情。

基础政策定义和具体实现分开登记：`market-environment-v1`保存固定参数，`market-environment-v1@<源码摘要>`保存独立实现身份，旧行不改写；计划另绑定执行构建摘要。评分政策使用新的独立版本，原版本和游标保留。同名基础参数被修改仍拒绝登记。

- `GET /api/market/environment?date=&at=`：返回该时点及以前已提交的环境、覆盖率、来源及预算影响。没有证据返回COLLECTING；只给at时使用该时点北京时间日期。
- `GET /api/research/environment?date=&buyPoint=&dimension=`：返回冻结报告、机会与完整周期分组、独立实验清单、三组比较。dimension为strength/direction/fragility。全部只读。

周期归档保存环境证据和原实验/报告；旧页面继续按原历史版本呈现。

## 上线及核验

启动时先用SQLite在线备份保存 `.sites-runtime/trading-archives/environment-startup-*/before.sqlite`，随后在盘前升级未使用计划，旧计划保留修订，新绑定与登记随事务提交。已有会话不改写，09:30后不补改当天计划，顺延至下一份未执行计划。不自动重启服务。

`node scripts/verify-market-environment.mjs`只读打开真实数据库，复制后执行迁移、模拟盘前升级和账本导出重放，结果写入 `.sites-runtime/environment-verification.json`。原库不被迁移或修改。测试另覆盖未来/迟到数据、未知样本、确认/降级、持仓保护、T恢复、真实部分成交、重复帧、CAS回滚、固定缺日窗口、日期聚类区间及成本压力。描述性验证不等于盈利验证。
