# 模拟练习的盈利模式研究闭环

状态：已实施。交易政策为 `dragon-risk-v1`，复盘为 `DRAGON_PRACTICE / schemaVersion: 3`。本文件与实现随 Git 管理；合成回归验证规则，不代表真实盈利结论。

## 每日采集与复盘

沿用免费 HTTP 行情及已配置的大模型。主账户启用龙头政策时，即使没有影子账户，也保存联合行情帧。09:30—11:30、13:00—14:57 连续竞价执行；15:00—15:05 单独采集收盘帧，该帧只归档、不追加模拟成交。已记录有效收盘帧时不重复采集。

正式研究日要求从两个连续竞价时段开始至末尾的连续观测，首尾容差 10 秒、帧间隔至多 20 秒。逐股核验实际准入后的报价、价格/量、买一卖一、市场阶段、行业及适用买点的竞价终态；另须有真实收盘帧和从会话起点记录的决策。实际行情轮询慢于 20 秒时仍可运行诊断，但不能贡献正式研究日。显式零挂单单独保留为已观测无流动性；原执行盘口可用性和成交规则不放宽。免费源没有历史完整逐笔队列，无法还原真实排队。

结算事务把 `closingBook` 与会话、净值一起冻结。执行分支记录实际准入、等待、买点、风控/现金/盘口拦截、过期及成交原因，绑定报价和市场输入的时间、序号；相同状态合并，计数只是观测次数。旧记录没有原因时保持未知。

原反馈接口继续返回旧评分、旧成交或新全账户复盘，历史行不重算为新口径。新复盘包括期初和期末持仓、全部实际准入候选、所有订单及成交。账户当日含费损益必须等于权益变化及逐股贡献之和；展示已实现损益、收盘历史成本浮盈、费用和已完成 T 净价差。跨日 T 只在配对日展示，T 价差不重复加入账户收益。

完整周期要求有已保存的首次 `OPEN`，并最终卖清，部分成交和 T 腿不扩大周期数。按首次买点、触发市场阶段和实际加仓/T 操作组合分组，保留净损益、周期数、胜率、盈亏比、持有日及保护退出周期数。操作组是相关性描述，不能证明单项操作的因果收益。入场后波动只使用入场后实际观测路径，路径不完整则不展示极值。

零成交也生成反馈：区分空仓/条件限制、拦截和数据缺口。有可靠账户或运行事实即可生成描述性 AI 复盘；结算未完成返回等待及原因，不补零收益。每日 AI 与正式提案共用 `practiceFeatures`，AI 文本和主观评分不进入正式提案或晋级计算。待验证假设必须引用客观特征类别并说明独立验证要求。

## 冻结研究与采用

新自动提案只能读取相邻 60 个完整训练日的客观特征；另有 20 个相邻封存测试日，之后观察固定的前 30 个新交易日。训练、测试和前瞻不会因缺日或未通过而延长。封存测试和前瞻日期保留一次性占用，失败、取消或重启不退还。

研究字段为六买点开关、盈利加仓、亏损补仓、双向 T 和三个高级数值参数。数值范围沿用配置校验器，单次步长分别为止损 0.005、T 比例 0.02、目标价差 0.005；每候选最多改两项。风险、资金、费用及撮合固定。同月最多一批，每批 1—4 个不同候选，候选、比较政策、账户锚点、源码指纹、输入摘要与统计序号事前冻结。统计预算按最多四个比较序号保守预占，未使用的序号不回收。

每个候选、匹配父策略及固定初始模板使用相同期初账户和原始行情，各自持有独立账本。固定模板启用全部买点和操作，使用既有默认高级参数，风险与本批父策略相同。历史与前瞻都重跑 1、1.5、2 倍成本；原始账本还必须通过逐日独立重放、资金核对和当前配置的真实整日技术报告。

所有成本情景都要求：候选净收益为正；分别比两个对照高至少 0.1 个百分点；回撤不超过各对照加 0.5 个百分点及用户上限；至少 10 个完整周期；通过原有配对区块重采样及全局尝试序号校正。净收益仍为负，即使亏得更少也拒绝。样本或证据不足记 `INCONCLUSIVE`，完整证据未过经济门槛记 `FAILED`，源码/费用/配置或摘要变动使冻结研究 `INVALIDATED`。

合格候选按净收益降序、回撤升序、参数改动幅度升序及 ID 排序，每批最多一个。自动改进模式在原子账户事务中排队，从下一份未冻结计划生效；人工模式保留批准流程。冻结计划、已有持仓风险基准、未完成 T、现金、参数及历史记录继续保留。执行源码更新沿用现有版本衔接，不在盘中改写已冻结计划。

源码升级时，尚未执行的旧版本计划与原观察名单保留修订；新版本计划、绑定及账户切换在同一事务提交。显式冻结的观察名单作为原始输入参与重放，候选及两个对照使用同一名单，盘中成交额、买点和风险门槛仍须逐次满足。已有执行会话的计划不改写。

研究维护有租约、版本 CAS 与统一窗口锁；中断的模型请求不重新生成候选，已冻结的历史测试不能跳过。研究计算使用逐日加载的帧并让出事件循环，重启继续同一批次和固定窗口，不能额外要求第 31 个前瞻日。

## 每周通知与查看

独立告警进程在每周五北京时间 17:15 起，通过已配置飞书发送一条冻结摘要，含全账户收益来源、费用、T 口径、数据缺口、完整周期分组、每日复盘摘要及研究阶段。当周没有练习会话或反馈则不发送；零成交但有练习记录仍发送。无需新增行情订阅或模型配置。

周报使用持久化周键、发送租约和 CAS 去重；明确的可重试失败最多五次。网络结果不明或发送中断标记 `UNCERTAIN`，避免重启后重复推送。配置区展示周报状态；可通过既有告警通道核对发送结果。

- 原 `/api/review`、历史反馈及 AI 复盘接口不变。
- `/api/paper/dragon` 的 `patternResearch` 展示窗口、候选、对照、源码/输入/报告摘要和各成本验证结果，`practiceWeekly` 展示周报投递状态。
- `/api/research/status` 的 `practice`、`weekly` 返回相同研究与通知状态。
- 迁移 `0033_practice_research.sql` 只追加研究/周报表，启动时自动应用；不清空模拟账户或历史。

验收运行 `npm run test:dragon`，包括完整 80 日合成源归档、训练/测试隔离、不同候选的相同对照、负收益/不足周期拒绝、全账户核算、跨日 T、盘口未知/零挂单、并发/重启去重、冻结清单及预算留存。另运行 V5 回归、旧成交反馈专项、界面测试、格式检查和构建。

真实结论只能是对应窗口的“找到较优模式”或“尚无合格模式”。旧历史缺少完整观测时不会被补造成合格样本，启动后需要持续积累实际完整交易日。
