# 龙头低吸选股法

基于"买在分歧，卖在一致"的A股超短选股与交易框架。核心逻辑：在市场公认的强势股（龙头）出现炸板、回调等分歧信号时低位介入，享受分歧转一致后的连板溢价，通过金字塔减仓锁定利润，走弱时清仓离场。同时建立股票分类体系，在无龙头机会时用波段股做T作为补充策略。

> **风险提示**：本技能仅提供选股思路与策略框架，不构成任何投资建议或买卖指令。超短交易风险极高，过往模式不代表未来有效。请结合自身风险承受能力独立决策。

## 核心原则（每日一读）

执行任何选股或交易前，先读一遍：

1. 交易你的计划，计划你的交易。
2. 勇于空仓勇于满仓。
3. 随机的交易往往是亏损的来源。
4. 不在平庸的股票上浪费生命。
5. 好东西都是需要去抢的。
6. 牛市思维对超短来说是致命的。
7. 不意淫，我们只是趋势的跟随者。
8. 在于盘中跟随，在跟随中应变，没有预判的跟随是盲从，没有应变的判断是意淫。

## 交易体系全景

### 战法分层

| 层级 | 战法 | 定位 | 仓位 | 预期收益 | 参与度 |
|---|---|---|---|---|---|
| **主战** | 龙头炸板低吸 + 连板持有 | 核心利润来源 | 6–8成 | 20–50%+ | 必做 |
| **主战** | 龙头打板 + 连板持有 | 确定性最高的进场方式 | 5–7成 | 15–40% | 有好板就打 |
| **辅战** | 假阴跌停低吸 | 炸板收假阴后博弈反包 | 4–6成 | 15–30% | 符合条件就做 |
| **辅战** | 龙头首阴低吸 | 次核心 | 4–6成 | 10–20% | 有机会就做 |
| **辅战** | 早盘竞价低吸（超预期低开） | 分歧日博弈反包 | 3–5成 | 8–15% | 符合条件就做 |
| **备用** | 波段股做T | 空仓期过渡 | 2–3成 | 3–8% | 可做可不做 |
| **自救** | 做T摊低成本 | 判断失误后的补救 | 1–2成加仓 | 减少亏损/微利 | 不得已而为之 |
| **休息** | 空仓等待 | 保存实力 | 0成 | 0% | 该空就空 |

### 股票分类体系

每只进入观察范围的股票，先归类——不同类别对应不同打法：

| 类别 | 特征 | 打法 | 优先级 |
|---|---|---|---|
| **连板龙头型** | 市场空间板、板块领涨、连板3板+ | 炸板低吸 + 连板持有 + 金字塔减仓 | ★★★★★ 最高 |
| **强势反包型** | 有涨停基因、走势强、但走的是趋势反包而非连板 | 回调低吸 + 趋势持有 | ★★★☆☆ 中等 |
| **波段震荡型** | 有题材支撑、走势波段上行、波动适中 | 尾盘低吸 + 隔日做T + 高抛低吸 | ★★☆☆☆ 低（可做可不做） |
| **平庸型** | 无涨停基因、走势弱、无辨识度 | 不做 | ☆☆☆☆☆ 排除 |

**分类不是固定的**——一只股票可能从"波段震荡型"升级为"连板龙头型"（如突然加速连板），也可能从"连板龙头型"降级为"波段震荡型"（如连板断了但趋势还在）。动态调整分类和策略。

## 主战：龙头低吸 + 连板持有

### 第一步：确定市场情绪周期

先判断当前市场处于什么阶段，决定仓位和策略：

| 情绪阶段 | 特征 | 操作策略 | 建议仓位 |
|---|---|---|---|
| **情绪上升期** | 连板高度持续打开、涨停家数多、炸板率低 | 积极进攻，大胆低吸龙头 | 6–8成 |
| **情绪高潮期** | 连板高度极高、市场亢奋、人人都是股神 | 谨慎，只做最强龙头的分歧 | 3–5成 |
| **情绪退潮期** | 高位股纷纷补跌、炸板率高、连板高度下降 | 空仓或极轻仓试错 | 0–2成 |
| **情绪冰点期** | 连板高度极低、涨停稀少、市场绝望 | 观察等待，准备迎接新周期 | 0成 |

**判断指标**（需结合实时盘面数据）：
- 连板最高板数（市场高度）
- 涨停家数 vs 跌停家数
- 炸板率（炸板数 / 涨停尝试数）
- 昨日涨停股今日溢价率
- 龙头股的走势强度

### 第二步：筛选龙头候选池

龙头股的核心特征：**市场辨识度高、带动性强、走势独立**。

#### 硬性筛选条件

- **涨停基因**：近期（5个交易日内）有过涨停，最好是连板
- **市场地位**：是当前热点板块的领涨股或空间板
- **辨识度**：股民讨论度高、龙虎榜有知名游资参与
- **流动性**：日成交额 ≥ 3亿，确保进出方便
- **股价位置**：处于近期新高或阶段高位（强者恒强）

#### 加分项

- 有明确的题材/概念支撑
- 板块内有跟风股，形成板块效应
- 龙虎榜显示有知名游资介入
- 量价配合健康（上涨放量、回调缩量）

#### 排除项

- ST/*ST 股票
- 新股上市前5日（无涨跌幅限制，波动不可控）
- 有重大利空或退市风险的股票
- 一字板上来的、没有换手的纯情绪票（开板即终点）

### 第三步：买点判断——打板与低吸

龙头股的买点分两大类：**追涨型（打板）**和**低吸型（各种分歧买点）**。
打板是"确定性最高的进场"，低吸是"性价比最高的进场"。

#### 买点类型一：打板买入（确定性最高）

**核心逻辑**：股票涨停的瞬间买入，赌的是"封住涨停 → 次日溢价 → 甚至连板"。
打板不是追高，而是**确认强势后的跟随**——能涨停本身就是最强的信号。

**触发条件**：
1. 股票是板块龙头或空间板（辨识度高）
2. 有明确的题材/逻辑支撑
3. 封板资金坚决，不是偷袭式拉板
4. 市场情绪处于上升期或高潮初期
5. 板块有联动效应，不是个股单打独斗

**什么样的板值得打？**

| 板的类型 | 质量 | 说明 |
|---|---|---|
| **早盘快速封板** | ★★★★★ | 资金抢筹意愿强烈，最优质的板 |
| **换手充分后封板** | ★★★★☆ | 换手充分，抛压消化完了再封，走得更远 |
| **午后回封板** | ★★★☆☆ | 炸板后回封，分歧转一致 |
| **尾盘偷袭板** | ★★☆☆☆ | 资金实力不足，次日溢价低 |
| **一字板（买不到）** | — | 没机会参与，开板了反而要小心 |

**打板的仓位**：
- 龙头首板/二板：5–7成
- 高位板（5板以上）：3–5成，谨慎
- 退潮期：不打或1成试错

**打板的纪律**：
1. **只打龙头，不打跟风**
2. **封不住就认错，不要硬扛**
3. **炸板后看承接，承接好可以拿着，承接差第二天走**
4. **打板不是目的，持有连板才是目的**

---

#### 买点类型二：炸板低吸（最经典）

**触发条件**：
1. 股票当天已经涨停过（封板时间越长越好，说明有资金做）
2. 盘中被砸开（炸板），出现明显回落
3. 回落幅度：从涨停价回落 3–7% 最佳（回落太少没安全垫，回落太多说明真弱）
4. 炸板时成交量放大但不极端（说明有承接，不是一泻千里）
5. 市场整体情绪没有崩盘（不是退潮期的全面杀跌）

**买点位置**：
- 激进型：炸板后回落到关键支撑位（如均价线、昨日收盘价）时买入
- 稳健型：观察尾盘，若能回封或企稳在均价线上方，尾盘集合竞价介入

**止损位**：买入当天收盘价跌破日内最低点，或次日低开超过3%且无反弹

#### 买点类型三：首阴低吸

**触发条件**：
1. 股票已经连续涨停3板以上
2. 出现第一根阴线（"首阴"）
3. 阴线实体不大（跌幅 3–5%），有长下影线更佳
4. 成交量放大但未爆量（爆量说明出货）
5. 5日均线未破

**买点位置**：
- 尾盘确认收阴但未破位时介入

#### 买点类型四：假阴跌停低吸（高赔率博弈）

**核心逻辑**：龙头股炸板后收一根"假阴线"（看起来是阴线，但实际收盘价高于前一天，或者跌幅不大、量能放大但承接尚可），次日跌停开盘——这是恐慌盘集中砸盘的结果，如果股票逻辑没坏，就是极佳的低吸博弈反包的机会。

> "炸板后考虑收个假阴，下周一跌停开也能梭哈套一波利"——这就是典型的假阴跌停低吸思路。

**什么是"假阴线"？**
- 当天高开低走，看起来是根大阴线
- 但收盘价其实没跌多少，甚至还是涨的
- 成交量放大，说明有大量换手
- 看起来吓人，实际承接不错

**触发条件**：
1. 股票是龙头或强势股，前期有涨停/连板
2. 当天炸板收假阴（高开低走但跌幅不大）
3. 成交量放大但不是爆量（有承接）
4. 次日跌停开盘或大幅低开（-8%以上）
5. 低开原因是情绪性杀跌，不是基本面利空
6. 市场情绪不是退潮期全面崩溃

**为什么跌停板反而可以买？**
- 假阴+跌停 = 恐慌盘集中释放
- 该卖的都卖了，抛压一次性出清
- 如果逻辑没坏，跌下去就是黄金坑
- 赔率极高：赌对了当天就能从跌停拉到涨停（地天板），赌错了也亏不了多少

**买点位置**：
- 跌停板挂单买入（需要排队，不一定能买到）
- 或者开盘后跌停打开、企稳时介入

**仓位建议**：
- 4–6成（比炸板低吸轻，因为不确定性更高）
- 不要真的"梭哈"，留有余地

**风险控制**：
- 如果当天封死跌停打不开，第二天必须止损
- 如果当天收不回均价线，第二天走
- 如果板块集体退潮，不要恋战

**成功的标志**：
- 跌停打开后迅速拉升
- 当天收大阳线甚至涨停（地天板）
- 成交量放大，资金承接明显

**失败的标志**：
- 封死跌停到收盘
- 打开后又反复封死，没有像样的反弹
- 第二天继续大跌

**注意**：这是高风险高收益的战法，只适合有经验的交易者，新手不要轻易尝试。

#### 买点类型五：尾盘跳水低吸

**触发条件**：
1. 强势股在尾盘（最后30分钟）突然跳水
2. 跳水幅度较大（3–5%）但不是跌停
3. 跳水时成交量没有极端放大
4. 当天大盘没有系统性风险

**买点位置**：
- 尾盘集合竞价，若能企稳在关键支撑位上方

#### 买点类型六：早盘集合竞价低吸（超预期低开）

**核心逻辑**：前一天强势的股票，第二天集合竞价大幅低开（甚至跌停），超出市场预期——这往往是恐慌盘砸出来的黄金坑，如果股票本身逻辑没坏、只是情绪错杀，就是低吸机会。

**触发条件**：
1. 前一天是强势股（涨停、大涨、或有明显主力运作痕迹）
2. 次日集合竞价大幅低开（低开 5% 以上，甚至跌停价开盘）
3. 低开原因是情绪性杀跌，而非基本面利空
4. 所属板块没有集体退潮
5. 市场情绪不是退潮期的全面杀跌

**为什么会有这种机会？**
- 前一天打板的人，竞价恐慌出逃
- 隔夜消息面有扰动，但实际影响不大
- 获利盘集中兑现，造成短期过度下跌

**买点位置**：
- 集合竞价最后几秒挂单买入（9:24–9:25）
- 或者开盘后第一波下探企稳时介入

**风险控制**：
- 仓位比炸板低吸轻（3–5成），因为不确定性更高
- 止损严格：如果开盘后继续下跌、跌破关键支撑，立刻止损
- 如果当天不能翻红或走强，次日必须走

**成功的关键标志**：
- 开盘后迅速拉红，说明有资金承接
- 当天能收阳线，最好是大阳线或涨停
- 成交量放大，说明分歧转一致

**失败的标志**：
- 开盘后一路下跌，毫无反弹
- 当天收大阴线，跌破关键均线
- 板块其他股票也在大跌，说明是系统性风险

### 第四步：仓位管理——金字塔建仓与减仓

#### 建仓

- **首次建仓**：5–8成仓（符合所有条件、确定性高时重仓）
- **不补仓**：低吸策略不补仓，买错了就止损，不要越跌越买

#### 减仓（金字塔式）

盈利后逐步减仓，让利润奔跑：

| 盈利幅度 | 减仓比例 | 剩余仓位 | 目的 |
|---|---|---|---|
| 第一个涨停（+10%左右） | 减 3成 | 5成 | 收回部分本金 |
| 第二个涨停 | 再减 2成 | 3成 | 锁定大部分利润 |
| 第三个涨停及以上 | 再减 1成 | 2成 | 底仓博傻，吃最后一段 |

**核心思想**：越涨越卖，降低成本，最后用"赚来的钱"持仓，心态最稳。

### 第五步：卖出信号识别

出现以下任一信号时，考虑清仓剩余仓位：

#### 明确卖出信号

1. **放量滞涨**：成交量创近期新高，但股价不涨或涨不动
2. **炸板不回封**：盘中涨停后被反复炸开，尾盘无法回封
3. **跌破5日均线**：短线趋势破位
4. **高位长上影线**：冲高回落，上方抛压沉重
5. **板块集体退潮**：同板块多只股票大跌，龙头独木难支
6. **情绪周期切换**：市场从高潮转向退潮，高位股开始补跌

#### 被动卖出（止损）

1. 买入后次日低开低走，跌破买入价 5%
2. 买入当天收盘浮亏超过 3%，且次日无反弹
3. 走势完全不符合预期，承认判断错误

## 龙头判断失误：降级处理与做T自救

### 什么是"判断失误"

你以为它是龙头，结果它走成了跟风——"走成了别人的小弟，还是个不称职的小弟。"

这种情况很常见，关键是**发现错了之后怎么处理**，而不是死扛或意淫。

### 判断失误的信号

出现以下情况，说明你可能把"跟风股"当成了"龙头股"：

1. **板块内有其他股票比它更强、涨得更高**
2. **它总是跟涨不领涨**——别人涨它才涨，别人跌它先跌
3. **涨停封不住、封板质量差**
4. **龙虎榜显示没有知名游资介入，都是散户和小资金**
5. **辨识度不够**——市场讨论度低，不是大家公认的龙头

### 处理策略：降级而不是死扛

发现判断失误后，**把这只股票从"连板龙头型"降级为"强势反包型"或"波段震荡型"**，对应调整策略：

| 原分类 | 降级后 | 策略调整 |
|---|---|---|
| 连板龙头型 → | 强势反包型 | 降低预期，不赌连板，有利润就减仓 |
| 连板龙头型 → | 波段震荡型 | 做T为主，高抛低吸，不格局 |
| 强势反包型 → | 波段震荡型 | 降低仓位，快进快出 |

**核心原则**：
- 预期要跟着走势调整，不能一条道走到黑
- 原来预期赚30%，现在发现是跟风股，赚10%就该满足
- 仓位也要跟着降级——龙头可以重仓，跟风只能轻仓

### 做T自救策略

如果已经被套或判断失误，可以用做T的方式摊低成本、减少亏损：

#### 做T的前提条件

1. **股票趋势没坏**：还在关键均线上方，不是破位下跌
2. **有波动空间**：每天有3–5%以上的振幅，才有做T的空间
3. **成交量正常**：不是缩量阴跌，有人买卖才有差价可赚
4. **你有时间盯盘**：做T需要实时看盘，没时间就别做

#### 正T（先买后卖）——适合低开高走

适用场景：股票低开，但你判断今天会反弹

操作：
1. 低开时加仓买入（用1–2成仓，不能加多）
2. 拉高后把加仓的部分卖出
3. 底仓不变，成本降低了

注意：
- 加仓的资金当天必须T出去，不能变成补仓
- 如果判断错了，低开低走，加仓的部分也要及时止损

#### 反T（先卖后买）——适合高开低走

适用场景：股票高开，但你判断今天会回落

操作：
1. 高开时先卖出一部分底仓
2. 回落后再买回来
3. 股数不变，成本降低了

注意：
- 卖飞了怎么办？——卖飞了就卖飞了，至少你赚了差价
- 不要因为卖飞了就追高买回来，那会越做越错

#### 做T的纪律

1. **做T仓位必须当天了结**——不能把做T变成补仓
2. **做T是为了降低成本，不是为了加仓**
3. **做错了及时止损**——不要越套越深
4. **趋势坏了就别做T了**——直接止损走人
5. **没把握就别做**——做反了反而增加亏损

### 什么时候该认输清仓

出现以下情况，说明做T也救不了，直接清仓认输：

1. **跌破关键支撑位**（如20日均线、前期平台）
2. **放量大跌**，说明主力出逃
3. **板块集体退潮**，独木难支
4. **基本面出现利空**
5. **做T越做越亏**，说明你的判断有问题

**认输不是失败，死扛才是。**
留得青山在，不怕没柴烧。

## 常见错误模式与复盘方法

### 为什么要研究错误

赚钱的交易各有各的运气，亏钱的交易却总是惊人地相似。
**研究错误比研究成功更重要——因为错误有模式，模式可以被识别和修正。**

### 典型错误模式一：错过正确时机 → 错误时机补救

**表现**：
1. 最佳买点出现时犹豫了、没动手
2. 事后后悔，想"补救"
3. 在错误的时机加仓/买入，试图弥补之前的错过
4. 结果越补越错，成本越来越高

**真实案例**：桂冠电力
> "21日早盘竞价买入当天收盘走低，没有果断尾盘加仓来扩大收益。当天复盘的时候意识到了错过了尾盘的加仓，结果犯了第二个错误，选择了第二天的早盘多加了一成仓位"

**为什么这是错的？**
- 第一天尾盘加仓是"顺势加仓"（走势确认后加仓）
- 第二天早盘加仓是"逆势补仓"（走势已经走坏了还加）
- 看似都是加仓，性质完全不同
- 出发点错了，后面的操作再精细也救不回来

**如何避免**：
1. 错过就错过，不要试图"补救"
2. 每一笔加仓都要有独立的买入逻辑，不能是"因为之前没买所以现在买"
3. 如果第一天错过了尾盘加仓，第二天要重新评估——走势变了，逻辑也变了
4. 错过的成本是0，做错的成本是负数

### 典型错误模式二：卖出参照位设定错误

**表现**：
- 不知道该以什么价格作为卖出/止损的参照
- 参照位设错了，导致该卖的时候没卖，不该卖的时候卖了
- 事后复盘才发现"原来应该以前二板为参照位"

**真实案例**：桂冠电力
> "22日当天复盘也没考虑清楚这个涨停板的意义，只是单纯的意识到23日可能会出现的低开低走，没有把卖出参照位设定在前二板11.68"

**常见的参照位错误**：
- ❌ 以自己的成本价为参照（"不回本不卖"）
- ❌ 以随便一个整数位为参照（"涨到10块就卖"）
- ❌ 参照位设得太近，容易被震出去
- ❌ 参照位设得太远，亏太多了才卖

**正确的参照位设定方法**：

| 参照位类型 | 适用场景 | 说明 |
|---|---|---|
| **前高/前板价位** | 连板股、强势股 | 前一个涨停板的价格是重要的心理位和支撑/压力位 |
| **5日均线** | 短线趋势股 | 跌破5日线说明短线趋势可能走坏 |
| **20日均线** | 波段股 | 跌破20日线说明波段趋势可能走坏 |
| **日内均价线** | 做T、日内交易 | 均价线上方强势，下方弱势 |
| **关键K线的最低点** | 止损位 | 跌破某根关键K线的最低点，说明走势可能反转 |

**设定原则**：
1. 参照位必须有技术意义，不能拍脑袋
2. 买入前就要想好卖出参照位，不能买了再想
3. 参照位要随着走势动态调整，不能一成不变
4. 参照位是"区域"不是"精确点位"，允许有误差

### 典型错误模式三：多逻辑体系冲突导致决策瘫痪

**表现**：
- 有好几套交易逻辑/体系
- 同一时刻，不同逻辑给出不同的结论
- 不知道该听哪一套的，导致决策犹豫
- 事后发现"其实另一套逻辑是对的，当时没敢信"

**真实案例**：哈药股份
> "17日的上板在我的另一套逻辑里是新的买点，虽然我当天的做T操作似乎更好，但是没能理顺所有逻辑，导致20日跌停板没敢梭哈，对当天收盘的假阳线也出现了认知偏差，从而21日提前离场"

**为什么会出现这种情况？**

1. **体系还没完全整合**：学了很多方法，但还没融合成一套自洽的体系
2. **不同体系的适用场景不同**：有的适合龙头，有的适合波段，混在一起用就乱了
3. **没有优先级**：不知道什么时候该用哪套逻辑，哪套逻辑说了算
4. **认知偏差**：当两套逻辑冲突时，倾向于相信自己"愿意相信"的那套

**如何解决多逻辑冲突**：

1. **给逻辑体系分层级、定优先级**
   - 主战逻辑（龙头低吸）> 辅战逻辑（首阴/竞价低吸）> 备用逻辑（波段做T）
   - 不同层级的逻辑，仓位不同、优先级不同
   - 高优先级逻辑给出信号时，低优先级逻辑让道

2. **明确每套逻辑的适用场景**
   - 龙头逻辑只适用于龙头股，不适用于波段股
   - 波段逻辑只适用于波段股，不适用于龙头股
   - 先给股票分类，再选择用哪套逻辑

3. **冲突时的决策原则**
   - 如果两套逻辑都指向同一个方向 → 加强信心，可以加仓
   - 如果两套逻辑方向相反 → 降低仓位，观望为主
   - 如果不确定哪套对 → 选择更保守的那个方案

4. **事后复盘要记录**
   - 每次出现逻辑冲突时，记录下来
   - 最后哪套逻辑对了？为什么？
   - 慢慢积累经验，提高判断力

### 典型错误模式四：做T越做越错

**表现**：
- 本来想做T降成本
- 结果做反了（正T做成了追高，反T做成了卖飞）
- 成本越做越高，仓位越做越重
- 最后从"做T"变成了"补仓"，越套越深

**真实案例**：桂冠电力
> "看来昨天没能及时做T还是比较伤的，今天跌停板加仓搏拉升也不理想"

**做T失败的常见原因**：
1. **趋势判断错了**：以为是低开高走，结果是低开低走
2. **做T仓位没及时T出去**：加了仓就舍不得卖，变成了补仓
3. **下跌途中不停做T**：趋势已经坏了还在做，越做越亏
4. **做T变成了赌博**：跌停板加仓搏拉升，赌输了就大亏

**做T的正确姿势**：
1. **只在趋势没坏时做T**，趋势坏了直接止损
2. **做T仓位必须当天了结**，不能过夜
3. **做错了及时认错**，不要硬扛
4. **连续做错两次就停手**，说明今天状态不对

### 复盘方法论

#### 每笔交易后必须回答的5个问题

1. **这笔交易的逻辑是什么？**
   - 为什么买？基于什么判断？
   - 买入逻辑事后验证是对是错？

2. **哪里做对了？**
   - 哪些操作是正确的？
   - 为什么能做对？是运气还是能力？

3. **哪里做错了？**
   - 哪些操作有问题？
   - 错误的原因是什么？（判断错误？执行错误？心态问题？）

4. **如果重来一次，会怎么做？**
   - 买入时机？仓位？卖出时机？
   - 这个"如果重来"的答案，就是你下次要执行的方案

5. **从中学到了什么？**
   - 有没有发现新的模式或规律？
   - 有没有暴露自己的盲区？
   - 这条经验可以推广到其他交易吗？

#### 复盘的正确姿势

- **及时复盘**：最好当天或第二天就复盘，记忆还新鲜
- **诚实面对**：不要找借口，不要美化自己的错误
- **记录下来**：好记性不如烂笔头，写下来才能积累
- **定期回顾**：每周/每月回顾一次，看看有没有重复犯同样的错误
- **重点研究亏钱的交易**：赚钱的交易可能是运气，亏钱的交易一定有问题

#### 复盘不是为了后悔

很多人复盘的目的是"如果当时那样做就好了"——然后陷入后悔。
**复盘的目的不是后悔，而是为了下次做得更好。**

- 过去的已经过去了，再后悔也没用
- 重要的是从中学到东西，下次不犯同样的错
- 每一笔亏损的交易，都是交学费——关键是你有没有真的学到东西

## 空仓纪律

### 空仓是最高级的操作

> "勇于空仓勇于满仓。"——这句话里，"勇于空仓"比"勇于满仓"更难，也更重要。

**会买的是徒弟，会卖的是师傅，会空仓的是祖师爷。**

### 什么时候必须空仓

出现以下情况，老老实实空仓，别手痒：

1. **没有符合自己模式的机会**
   - 观察池里没有A级标的
   - 没有出现符合条件的买点
   - 市场上的涨停都不是你的模式内的
   - → 那就等，强行交易=送钱

2. **情绪退潮期**
   - 高位股集体补跌
   - 炸板率极高
   - 打板亏多赚少
   - → 退潮期不做就是赚

3. **连续做错的时候**
   - 连续几笔交易都亏了
   - 手感不好、状态不对
   - → 停下来休息，调整状态再上场

4. **看不懂的时候**
   - 市场走势混乱，没有清晰的主线
   - 板块轮动太快，抓不住
   - → 看不懂就不做，没人逼你必须交易

5. **心态不好的时候**
   - 刚大亏了一笔，想捞回来
   - 因为错过而焦虑，想追高
   - 生活中有其他事情影响情绪
   - → 心态不好时交易，大概率会越做越错

### 空仓期间做什么

空仓不是什么都不做，而是**做交易之外的准备工作**：

1. **复盘**：
   - 回顾最近的交易，总结经验教训
   - 分析市场上的牛股，研究它们的走势
   - 更新自己的交易体系

2. **选股**：
   - 筛选值得关注的股票，更新观察池
   - 研究板块逻辑，寻找下一波机会
   - 准备好，等机会来的时候才能抓住

3. **学习**：
   - 看别人的复盘，学习新的思路
   - 读交易相关的书籍和文章
   - 提升自己的认知水平

4. **休息**：
   - 交易是脑力劳动，需要休息
   - 陪陪家人，做点别的事情
   - 保持好心态，比什么都重要

### 空仓的心理建设

#### 为什么大多数人做不到空仓？

1. **手痒**：不交易就难受，总觉得手里有票才安心
2. **怕错过**：万一空仓的时候大涨了怎么办？
3. **焦虑**：别人都在赚钱，我空仓是不是落后了？
4. **无聊**：没事干，不交易就觉得虚度了

#### 如何克服？

1. **接受"错过是常态"**
   - 市场永远不缺机会，缺的是耐心
   - 你不可能抓住每一波行情
   - 错过不是亏损，做错才是

2. **算一笔账**
   - 假设你一年只做5笔确定性高的交易，每笔赚15%
   - 复利下来：1.15^5 ≈ 2.01，一年翻倍
   - 比你天天交易、赚赚亏亏强多了

3. **把空仓当成一种仓位**
   - 空仓不是"没持仓"，而是"持有现金"
   - 现金也是一种仓位，而且是最安全的仓位
   - 等待机会的过程，就是持币观望的过程

4. **给自己定规矩**
   - 比如：每周最多交易2次
   - 比如：没有A级机会就不开仓
   - 比如：连续亏损2笔就空仓休息3天
   - 用规则代替情绪

### 实战案例：空仓一周

**背景**：8月6日清仓传智教育后，一直空仓到8月13日，8月14日才建仓皇氏集团。
**空仓时长**：5个交易日（一周）

**为什么这很重要？**

1. **不是卖了就立刻找下一只**
   - 很多人卖了一只票，当天就急着买下一只，生怕踏空
   - 他没有，他等了整整一周
   - 说明他在等符合自己模式的机会，而不是为了交易而交易

2. **有耐心，能等**
   - 一周时间，市场上肯定有涨停的股票
   - 但他都没动手，说明那些都不是他的菜
   - "宁可错过，不可做错"——他真的做到了

3. **出手就有章法**
   - 等了一周才出手的皇氏集团，用的是早盘竞价低吸战法
   - 虽然最后证明不是龙头，但他有完整的应对方案
   - 做对了赚钱，做错了也能全身而退

**这就是成熟交易者和散户的区别：**
- 散户：天天交易，生怕错过任何机会，结果亏多赚少
- 成熟交易者：大部分时间在等待，只在确定性高的时候出手，一击必中

## 备用：波段股做T策略

当市场没有好的龙头低吸机会、但又不想完全空仓时，用波段股做T来过渡。

**定位**：可做可不做，赚点零花钱，别指望大赚。

### 波段股的特征

- 有题材/概念支撑，但不是当前最热的
- 走势是波段上行，不是连板加速
- 波动适中，每天有3–5%的振幅
- 成交量稳定，不会突然爆量或缩量
- 有一定辨识度，但不是市场总龙头

### 操作方式

#### 买入：尾盘集合竞价

- 收盘前最后几分钟买入
- 选择当天走势稳健、量能正常的票
- 价格在关键支撑位上方（如5日、10日均线）

#### 次日操作预案（必须提前想好）

| 次日走势 | 操作 |
|---|---|
| **低开拉高** | 拉高时卖出，做正T赚差价 |
| **低开低走** | 考虑加仓（摊低成本），等反弹再T出去 |
| **高开高走** | 持有观察，走弱再卖 |
| **高开低走** | 冲高时先卖，不恋战 |

**核心逻辑**：
- 波段股不格局，有赚就跑
- 做T的目的是降低成本或赚差价，不是拿长线
- 做错了及时止损，不要把短线做成中线

### 仓位控制

- 单票 2–3成仓，轻仓参与
- 总仓位不超过5成
- 这是"打发时间"的玩法，别重仓

## 观察池与交易计划

### 观察池的建立

每天盘后筛选出值得关注的股票，放入观察池，分为三个等级：

| 等级 | 名称 | 含义 | 操作 |
|---|---|---|---|
| **A级** | 重点关注 | 大概率有交易机会 | 次日重点盯盘，准备进场 |
| **B级** | 一般关注 | 有机会但确定性一般 | 观察走势变化，符合条件再考虑 |
| **C级** | 备选观察 | 可做可不做的类型 | 有时间就看看，没时间就忽略 |

### 交易计划的制定

**每天盘后必须做的功课**：

1. **复盘今天的操作**：哪里做对了，哪里做错了
2. **更新观察池**：哪些票升级，哪些票降级，哪些剔除
3. **制定明日计划**：
   - 关注哪几只票
   - 什么条件下买
   - 买多少仓位
   - 什么条件下卖
   - 止损位在哪里

**计划模板**：
```
明日计划：
- [股票A]：如果[条件]，就在[价位]买入[X成]，止损[X元]
- [股票B]：开盘不及预期就放弃
- 持仓[股票C]：明日若低开拉高出，低开低走考虑加仓
```

**关键纪律**：
- 没有计划的交易不做
- 不符合计划的走势不强行交易
- 开盘不及预期就放弃，不要硬上
- "错过"不是亏损，乱做才是

## 可视化 HTML 看盘报告（必交付物）

执行"寻找候选 / 明日计划 / 选股分析"类任务时，**除文字报告外，必须生成一个自包含的可视化 HTML 看盘报告**，让用户打开就知道明天怎么看盘、怎么操作。

### 文件要求

- 自包含单文件：CSS/JS 全部内联，不依赖任何外部资源（断网也能打开）
- 浅色主题、深色文字；A股配色：涨=红、跌=绿
- 文件名：`明日候选_看盘报告_YYYYMMDD.html`，存放于工作区 `outputs/` 目录
- 生成后必须用 present_files 交付

### 报告固定结构（从上到下，缺一不可）

1. **顶部横幅**：日期 + 情绪周期定位（上升/高潮/退潮/冰点/退潮修复期）+ 总仓位建议
2. **情绪数据卡**（2x2 或 2x3 网格）：涨停/跌停、炸板率、连板晋级率、最高板、成交额、上涨家数（涨红跌绿着色）
3. **明日看盘时间轴**（教用户"怎么看盘"，按时间节点从上到下）：
   - 9:15-9:25 竞价观察：主线龙头竞价低开幅度、跌停家数、昨日涨停溢价
   - 9:25-9:30 竞价定夺：低开≥5%且板块不崩 → 记入低吸候选；高标核按钮 → 直接放弃
   - 9:30-10:00 承接确认：低吸标的开盘后是否快速翻红、站稳分时均价线
   - 盘中：跟踪涨停晋级家数、炸板率变化、龙头分时承接
   - 14:30-15:00 尾盘决策：回封/企稳确认 → 尾盘介入；走弱 → 空仓
4. **候选池分级卡片**（A级/B级/C级，每只一卡）：股票分类、连板高度、买点类型、关注价位、止损位、证伪条件、次日预案（低开拉高/低开低走/高开高走/高开低走）
5. **明日决策树**：情景 A/B/C/D → 触发条件 → 操作动作 → 建议仓位
6. **纪律检查清单**：可交互勾选（原生 checkbox），覆盖 skill 核心纪律
7. **免责声明**：固定标注"仅为策略框架推演，不构成投资建议"

### 交互与样式要求

- 检查清单用原生 checkbox 实现勾选，交互必须可用
- 数据卡/候选卡静态呈现即可，不引入复杂框架
- 字号不小于 11px，不使用 emoji，所有数值保留 1-2 位小数
- 未知的关键价位（如次日的竞价价）标注"以实际盘面为准"，**不得编造**

## 重要约束

- 本技能仅提供选股思路和策略框架，**不得输出具体买卖建议、目标价、收益预期**
- 所有结论均为条件式判断，必须标注"不构成投资建议"
- 选股结果需要用户结合实时盘面独立判断
- 不得回测历史数据并声称"该策略胜率X%"
- 超短交易风险极高，大多数交易者亏损，需谨慎对待
