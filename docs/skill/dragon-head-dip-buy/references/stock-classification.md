# 股票分类与观察池指南

## 一、股票分类体系

### 1.1 分类的意义

不同类型的股票，对应不同的交易策略。
用错了方法，好股票也能亏成狗。

先分类，再决定用什么战法。

### 1.2 四大分类

#### 第一类：连板龙头型 ⭐⭐⭐⭐⭐

**核心特征**：
- 连续涨停（3板以上）
- 是市场空间板或板块领涨股
- 辨识度极高，全市场都在看
- 有明确的题材/逻辑支撑
- 龙虎榜有知名游资参与

**典型走势**：
- 一波流连板，中间可能有炸板分歧
- 分歧后继续连板，直到情绪退潮
- 涨幅大、速度快、周期短

**对应战法**：
- 炸板低吸（主战）
- 首阴低吸（辅战）
- 金字塔减仓
- 走弱清仓

**仓位**：6–8成重仓

---

#### 第二类：强势反包型 ⭐⭐⭐

**核心特征**：
- 有涨停基因，但不是连板走势
- 走的是"涨—调—涨"的反包节奏
- 趋势向上，高点不断抬高
- 有题材但不是最热题材
- 股性活跃

**典型走势**：
- 涨停后调整1–2天，然后反包再涨停
- 或者走趋势，涨几天调几天
- 整体向上，但节奏不如连板股快

**对应战法**：
- 回调低吸
- 反包确认后加仓
- 趋势持有，跌破均线卖

**仓位**：4–6成

---

#### 第三类：波段震荡型 ⭐⭐

**核心特征**：
- 有题材/概念，但不是当前主线
- 走势是波段上行，不是连板
- 每天有3–5%的振幅，适合做T
- 成交量稳定，不会大起大落
- 有一定辨识度，但不是市场焦点

**典型走势**：
- 沿着5日或10日均线缓慢上行
- 涨几天调几天，波段特征明显
- 整体涨幅不大，但波动有规律

**对应战法**：
- 尾盘低吸 + 隔日做T
- 高抛低吸，波段操作
- 不格局，有赚就跑

**仓位**：2–3成轻仓

**定位**：可做可不做，空仓期打发时间用的。
别指望赚大钱，别重仓。

---

#### 第四类：平庸型 ⭐

**核心特征**：
- 无涨停基因
- 走势弱于大盘
- 无辨识度，没人关注
- 成交量低迷

**对应战法**：
- 不做

**仓位**：0成

---

### 1.3 分类的动态调整

股票分类不是一成不变的，要根据走势动态调整：

**升级路径**：
- 波段震荡型 → 强势反包型：开始出现涨停，股性激活
- 强势反包型 → 连板龙头型：连续涨停，成为市场焦点

**降级路径**：
- 连板龙头型 → 强势反包型：连板断了，但趋势还在
- 强势反包型 → 波段震荡型：涨停没了，回归波段走势
- 任何类型 → 平庸型：走坏了，剔除观察池

**判断升级/降级的关键信号**：
- 涨停（股性激活）→ 可能升级
- 连板（强度提升）→ 升级
- 跌破关键均线 → 可能降级
- 成交量持续萎缩 → 降级
- 板块退潮 → 降级

## 二、观察池的建立与维护

### 2.1 为什么要有观察池

- **避免临时决策**：盘中临时起意的交易，大概率是亏的
- **提前做功课**：盘后选好标的，想好策略，盘中只负责执行
- **跟踪变化**：持续观察一只股票的走势变化，比每天换新股更了解它
- **分类管理**：不同优先级的票，投入的精力不同

### 2.2 观察池的三级分类

| 等级 | 名称 | 数量 | 含义 | 操作频率 |
|---|---|---|---|---|
| **A级** | 重点关注 | 2–3只 | 大概率有交易机会 | 每天必看，次日重点盯盘 |
| **B级** | 一般关注 | 3–5只 | 有机会但确定性一般 | 每天看一眼，有变化再深入 |
| **C级** | 备选观察 | 5–10只 | 可做可不做的类型 | 偶尔看看，没时间就忽略 |

### 2.3 如何筛选进入观察池

#### 进入A级观察池的条件（满足全部）

1. 属于"连板龙头型"或"强势反包型"
2. 有明确的题材/逻辑支撑
3. 走势健康，量价配合
4. 近期可能出现买点（炸板、回调等分歧信号）
5. 市场情绪环境配合

#### 进入B级观察池的条件（满足大部分）

1. 属于"强势反包型"或"波段震荡型"
2. 有一定题材支撑
3. 走势尚可，但还没到买点
4. 需要进一步观察确认

#### 进入C级观察池的条件

1. 属于"波段震荡型"
2. 有题材但不是主线
3. 走势有规律，适合做T
4. 没什么大机会，但可以偶尔看看

### 2.4 观察池的日常维护

**每天盘后做的事**：

1. **复盘现有观察池**：
   - 每只票今天走势怎么样？
   - 有没有出现买点信号？
   - 有没有出现卖出信号？
   - 分类需要调整吗？

2. **调整等级**：
   - 走势变强 → 升级（C→B，B→A）
   - 走势变弱 → 降级（A→B，B→C，C→剔除）
   - 走坏了 → 直接剔除

3. **加入新标的**：
   - 当天涨停的股票里有没有值得关注的？
   - 有没有新题材出现？
   - 有没有股票出现了值得关注的形态？

4. **制定明日计划**：
   - A级票：详细计划（什么条件买、买多少、止损在哪）
   - B级票：大概计划（关注什么信号）
   - C级票：不用计划，看着就行

### 2.5 观察池的纪律

- **数量控制**：A级不超过3只，B级不超过5只，太多了看不过来
- **定期清理**：走坏的票及时剔除，不要舍不得
- **不恋旧**：曾经的龙头不代表永远是龙头，走坏了就删掉
- **不追新**：每天都有新涨停，不要见一个爱一个
- **聚焦主线**：观察池里的票尽量集中在当前主线题材上

## 三、交易计划的制定

### 3.1 为什么要有交易计划

"交易你的计划，计划你的交易。"

没有计划的交易 = 随机交易 = 大概率亏损

### 3.2 交易计划的要素

一个完整的交易计划必须包含：

| 要素 | 说明 | 示例 |
|---|---|---|
| **标的** | 买什么股票 | 传智教育（003032） |
| **买入条件** | 什么情况下买 | 炸板回落到均价线附近 |
| **买入价位** | 大概什么价格买 | 8.2元附近 |
| **仓位** | 买多少 | 6成仓 |
| **止损位** | 错了怎么办 | 跌破8元止损 |
| **次日预案** | 第二天各种走势怎么应对 | 低开拉高就卖，低开低走加仓 |
| **预期持仓周期** | 大概拿多久 | 3–5天 |

### 3.3 次日预案模板

对持仓的股票，必须提前想好第二天各种走势的应对方案：

```
[股票名称] 次日预案：
- 情况一：低开拉高 → 拉高时卖出X成
- 情况二：低开低走 → 考虑加仓X成（前提是趋势没坏）
- 情况三：高开高走 → 持有观察，走弱再减
- 情况四：高开低走 → 冲高先卖，不恋战
- 情况五：涨停 → 继续持有，看封板质量
```

### 3.4 计划的执行与应变

- **计划内的走势**：严格按计划执行
- **计划外的走势**：先观察，不急于行动，想清楚再决策
- **不及预期**：该放弃就放弃，错过不是亏损
- **超预期**：可以适当加仓，但别上头

**核心原则**：
- 计划是用来执行的，不是用来摆着看的
- 但计划也不是死的，可以根据实际情况调整
- 调整的前提是：你想清楚了为什么调整，而不是因为情绪冲动

## 四、错过的处理

### 4.1 错过是常态

- 不可能抓住每一个机会
- 错过不是亏损，乱做才是
- 市场永远不缺机会，缺的是耐心和纪律

### 4.2 错过后的正确心态

- **不懊悔**：错过了就错过了，下次还有机会
- **不追高**：因为错过而追高，是最容易亏钱的操作
- **总结经验**：为什么错过了？下次能不能更早发现？
- **等待下一个**：把精力放在寻找下一个机会上，而不是纠结上一个

### 4.3 从错过中学习

每次错过一个好机会，都要复盘：

1. 为什么没选进观察池？
   - 没发现这只票？→ 选股范围需要扩大
   - 发现了但判断错了？→ 选股标准需要调整

2. 为什么没买？
   - 没注意到买点信号？→ 盯盘不够
   - 注意到了但不敢买？→ 心态问题，需要修炼
   - 想买但没仓位了？→ 仓位管理问题

3. 下次怎么避免错过？
   - 优化选股标准
   - 扩大观察范围
   - 提高执行力

**但记住**：错过永远比做错好。
宁可错过，不可做错。
