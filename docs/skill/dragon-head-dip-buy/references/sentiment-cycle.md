# 情绪周期判断指南

情绪周期是龙头低吸策略的"天时"。在正确的情绪阶段做正确的事，比选对股票更重要。

---

## 一、情绪周期四阶段

### 1. 冰点期 → 启动期

**特征：**
- 连板高度极低（2–3板甚至更低）
- 涨停家数稀少（< 30家）
- 跌停家数较多
- 市场情绪低迷，人人谈股色变
- 炸板率极高，打板亏多赚少

**操作策略：**
- 空仓观望为主
- 密切关注谁率先走出高度
- 新周期的第一只龙头股往往涨幅最大
- 小仓位试错新题材的首板或二板

### 2. 启动期 → 上升期

**特征：**
- 有一只股票率先打出高度（4–5板）
- 涨停家数开始增加
- 炸板率下降，打板开始赚钱
- 市场开始有赚钱效应
- 板块轮动加快，但已有主线雏形

**操作策略：**
- 积极参与，重点做龙头
- 炸板低吸的黄金时期
- 仓位可以提到6–8成
- 敢于追高龙头，不要恐高

### 3. 上升期 → 高潮期

**特征：**
- 连板高度持续打开（7板以上）
- 涨停家数很多（> 80家甚至上百家）
- 普涨行情，鸡犬升天
- 市场亢奋，身边人都在赚钱
- 垃圾股也能涨停，板块效应扩散

**操作策略：**
- 继续持有龙头，但开始谨慎
- 减仓节奏加快，不要格局太久
- 不碰后排跟风股，只做最强龙头
- 警惕高潮后的退潮

### 4. 高潮期 → 退潮期

**特征：**
- 高位股开始补跌
- 炸板率急剧上升
- 连板高度下降
- 涨停家数减少，跌停家数增加
- 前一天涨停，第二天低开闷杀

**操作策略：**
- 快速降低仓位，甚至空仓
- 不抄底，不接飞刀
- 退潮期的每一次反弹都是卖点
- 保护利润，等待下一个周期

## 二、情绪判断指标

### 2.1 核心指标

| 指标 | 说明 | 数据来源 |
|---|---|---|
| **连板最高板数** | 市场高度，情绪的天花板 | 每日涨停板复盘 |
| **涨停家数** | 市场赚钱效应的广度 | 行情软件 |
| **跌停家数** | 市场亏钱效应的广度 | 行情软件 |
| **炸板率** | 打板的难度和风险 | 炸板数 / 涨停尝试数 |
| **昨日涨停溢价** | 前一天打板的人今天赚多少 | 昨日涨停指数 |
| **连板晋级率** | 连板股的持续性 | 今日连板数 / 昨日连板数 |

### 2.2 辅助指标

- **龙虎榜**：知名游资的动向
- **北向资金**：外资的流入流出
- **大盘成交量**：市场参与热度
- **涨跌家数比**：多空力量对比
- **板块轮动速度**：轮动快说明情绪不稳

## 三、不同情绪阶段的龙头低吸策略

### 上升期：大胆干

- **策略**：炸板低吸为主，首阴低吸为辅
- **仓位**：6–8成
- **选股**：只做最高空间板和板块龙头
- **持有**：连板就拿着，不急着卖
- **止损**：给的容错空间大一点（5–7%）

### 高潮期：谨慎干

- **策略**：只做最强龙头的分歧，不做后排
- **仓位**：3–5成
- **选股**：只做市场总龙头，其他不看
- **持有**：减仓节奏加快，有利润就兑现
- **止损**：严格止损（3–5%）

### 退潮期：尽量别干

- **策略**：空仓为主，手痒就1成仓试错
- **仓位**：0–2成
- **选股**：新题材的首板或低位首板
- **持有**：赚了就跑，不格局
- **止损**：错了立刻砍，不要犹豫

### 冰点期：别干

- **策略**：空仓等待，保存实力
- **仓位**：0成
- **工作**：复盘、学习、观察谁可能成为下一个龙头
- **心态**：耐心等待，机会是等出来的

## 四、情绪周期切换的信号

### 上升期 → 高潮期的信号

- [ ] 连板高度突破前高
- [ ] 涨停家数持续在高位
- [ ] 人人都在讨论股票
- [ ] 垃圾股也能连板
- [ ] 新手开始赚钱

### 高潮期 → 退潮期的信号

- [ ] 高位股开始出现大面（炸板亏10%+）
- [ ] 连板高度突然下降
- [ ] 跌停家数增加
- [ ] 前一天的涨停股第二天低开闷杀
- [ ] 板块轮动加快，没有持续性

### 退潮期 → 冰点期的信号

- [ ] 连板高度降到2–3板
- [ ] 打板几乎必亏
- [ ] 市场情绪绝望
- [ ] 成交量萎缩

### 冰点期 → 启动期的信号

- [ ] 有股票率先走出4板以上高度
- [ ] 涨停家数开始增加
- [ ] 炸板率下降
- [ ] 有新题材出现并形成板块效应
- [ ] 市场开始有赚钱效应

## 五、情绪判断的常见误区

### 误区一：把高潮当启动

- 表现：已经涨了很多了才冲进去，接最后一棒
- 对策：看连板高度，已经7板以上了就不是启动期了

### 误区二：把反弹当反转

- 表现：退潮期的一次反弹就以为新周期来了
- 对策：看持续性，反弹通常只有1–2天

### 误区三：恐高

- 表现：龙头涨了不敢买，去买后排跟风
- 对策：龙头才是最安全的，跟风股才是最危险的

### 误区四：抄底退潮期

- 表现：高位股跌了很多了，以为跌到位了去抄底
- 对策：退潮期不言底，不要接飞刀

### 误区五：冰点期放弃

- 表现：市场太差了，不看了
- 对策：冰点期是下一波行情的起点，这个时候更要好好复盘选股
