# 选股条件清单

## 一、龙头股筛选标准

### 1.1 硬性条件（必须全部满足）

| 条件 | 标准 | 说明 |
|---|---|---|
| 近期涨停 | 5个交易日内有涨停 | 有涨停基因才可能成为龙头 |
| 市场地位 | 板块内涨幅第一或连板高度最高 | 龙头必须是领涨的 |
| 流动性 | 日成交额 ≥ 3亿 | 确保进出方便，不会被闷杀 |
| 股价位置 | 处于20日新高或阶段高位 | 强者恒强，不抄底弱势股 |
| 非ST | 非ST/*ST/退市整理 | 排除基本面风险 |

### 1.2 加分项（满足越多越好）

- 有明确的政策/事件/产业题材支撑
- 所属板块有3只以上涨停股（板块效应）
- 龙虎榜有知名游资买入
- 上涨放量、回调缩量（量价健康）
- 股性活跃，历史上有过连板记录
- 流通市值适中（30亿–200亿最佳）
- 有业绩支撑或基本面改善预期

### 1.3 减分项（出现需谨慎）

- 纯概念炒作，无任何基本面支撑
- 一字板上来，没有充分换手
- 大股东减持或有解禁压力
- 前期涨幅过大（累计涨幅 > 200%）
- 龙虎榜显示机构大幅卖出
- 尾盘偷袭涨停，非主动上攻

## 二、买点判断标准

### 2.0 打板买入条件

**核心原则**：打板是"确认强势"，不是"追高"。只打龙头的板，不打跟风的板。

**最佳打板条件：**
1. 是板块龙头或空间板，辨识度高
2. 有明确的题材/逻辑支撑
3. 封板坚决，量价配合健康
4. 市场情绪处于上升期或高潮初期
5. 板块有联动效应

**板的质量评级：**

| 等级 | 板型 | 特征 | 打不打 |
|---|---|---|---|
| S级 | 早盘快速封板 | 开盘半小时内封死，封单大，换手充分 | 重仓打 |
| A级 | 换手后封板 | 上午换手充分后封板，抛压消化完了 | 可以打 |
| B级 | 午后回封板 | 上午炸板，下午回封，分歧转一致 | 轻仓试 |
| C级 | 尾盘偷袭板 | 最后半小时拉板，资金实力不足 | 不打 |
| D级 | 一字板 | 买不到，开板了反而要小心 | 不碰 |

**打板仓位对照表：**
- 龙头首板/二板 + 情绪上升期：5–7成
- 龙头3–4板 + 情绪高潮期：3–5成
- 龙头5板以上：2–3成，谨慎
- 退潮期：不打或1成试错

**打板纪律（铁律）：**
- [ ] 只打龙头，不打跟风
- [ ] 只打有题材的板，不打无厘头拉板
- [ ] 封不住就认错，不要意淫回封
- [ ] 炸板后看承接，承接好可以拿，承接差第二天走
- [ ] 退潮期少打板，手痒就小仓位试错
- [ ] 连续打错2次就停手休息

---

### 2.1 炸板低吸买点

**最佳条件组合：**
1. 早盘快速封板，封板时间 ≥ 1小时
2. 盘中炸板，回落幅度 3%–7%
3. 炸板时成交量放大但未爆量（≤ 前一日1.5倍）
4. 回落至均价线附近获得支撑
5. 炸板后有承接，不是一路下跌
6. 市场情绪处于上升期或高潮初期

**最差情况（避免）：**
- 尾盘才封板，封板不到半小时就炸
- 炸板后一路向下，毫无承接
- 炸板时放出天量（> 前一日2倍）
- 市场处于退潮期，高位股集体杀跌

### 2.2 首阴低吸买点

**最佳条件组合：**
1. 连续涨停 ≥ 3板
2. 第一根阴线，跌幅 3%–5%
3. 有长下影线（说明下方有承接）
4. 5日均线未破
5. 成交量放大但未爆量
6. 收盘仍在昨日收盘价上方或附近

**最差情况（避免）：**
- 跌停式首阴（一字跌停或放量大跌）
- 跌破5日均线
- 首阴前已经是加速赶顶形态
- 板块已经开始退潮

### 2.3 假阴跌停低吸买点（高赔率博弈）

**核心逻辑**：炸板收假阴 + 次日跌停 = 恐慌盘集中释放，逻辑没坏就是黄金坑。

**什么是假阴线：**
- 高开低走，K线是绿的（阴线）
- 但实际跌幅不大，甚至还是涨的
- 成交量放大，换手充分
- 看起来吓人，实际承接不错

**最佳条件组合：**
1. 前期是强势股/龙头股，有涨停/连板
2. 当天炸板收假阴（高开低走但跌幅 ≤ 3%）
3. 成交量放大但未爆量（≤ 前一日2倍）
4. 次日跌停开盘或大幅低开（-8%以上）
5. 低开原因是情绪性杀跌，不是基本面利空
6. 市场情绪不是退潮期全面崩溃
7. 所属板块没有集体退潮

**可以重仓的信号（梭哈级）：**
- [ ] 跌停板有大量承接，封单不大
- [ ] 开盘后迅速打开跌停
- [ ] 打开后放量拉升
- [ ] 板块内其他股票没有大跌

**必须放弃的信号：**
- [ ] 封死跌停到收盘，封单巨大
- [ ] 有实质性利空消息
- [ ] 板块集体跌停，系统性风险
- [ ] 市场处于退潮期高潮

**仓位建议：**
- 标准情况：4–6成
- 信号特别好（有大量承接）：6–8成
- 信号不确定：2–3成试错
- 退潮期：不做或1成

**止损纪律：**
- 当天封死跌停打不开 → 第二天无条件止损
- 当天收不回均价线 → 第二天减仓或走人
- 买入逻辑被证伪（如出现利空）→ 立刻走

---

### 2.4 尾盘跳水低吸买点

**最佳条件组合：**
1. 当天大部分时间走势强势
2. 尾盘（14:30后）突然跳水
3. 跳水幅度 3%–5%
4. 跳水时量能没有极端放大
5. 跳水后在关键支撑位企稳
6. 大盘没有系统性风险

### 2.5 早盘集合竞价低吸买点

**核心逻辑**：前一天强势股次日竞价超预期低开/跌停，恐慌盘砸出黄金坑，博弈反包。

**最佳条件组合：**
1. 前一天是强势股（涨停/大涨，有明显主力运作）
2. 次日集合竞价大幅低开（低开 5%+ 或跌停）
3. 低开原因是情绪性杀跌，不是基本面利空
4. 所属板块没有集体退潮
5. 市场情绪不是退潮期全面杀跌
6. 竞价有承接（不是封死跌停的一字板）

**仓位建议**：3–5成（比炸板低吸轻，因为不确定性更高）

**最差情况（避免）：**
- 有实质性利空消息导致的低开
- 板块集体退潮，不是个股问题
- 竞价封死跌停，没有承接
- 市场处于退潮期，情绪崩溃
- 股票本身已经走坏，不是错杀

**成功标志**：
- 开盘后迅速拉红
- 当天收阳线（最好是大阳或涨停）
- 成交量放大，有资金承接

**失败标志**：
- 开盘后一路下跌，毫无反弹
- 当天收大阴线，跌破关键均线
- 板块其他股票也在大跌

## 三、做T自救条件清单

### 3.1 适合做T的情况

- [ ] 股票趋势没坏，还在关键均线上方
- [ ] 每天有 3%–5% 以上的振幅
- [ ] 成交量正常，不是缩量阴跌
- [ ] 你有时间盯盘
- [ ] 判断是短期波动，不是趋势反转

### 3.2 不适合做T的情况

- [ ] 趋势已经破位（跌破20日均线/前期平台）
- [ ] 放量大跌，主力出逃
- [ ] 基本面出现利空
- [ ] 没有时间盯盘
- [ ] 做T技术不好，经常做反
- [ ] 仓位已经很重了

### 3.3 正T（先买后卖）操作要点

适用场景：低开高走预期

1. 低开时加仓 1–2 成（不能加多）
2. 拉高后把加仓的部分卖出
3. 底仓不变，成本降低
4. 当天必须T出去，不能变成补仓

### 3.4 反T（先卖后买）操作要点

适用场景：高开低走预期

1. 高开时先卖出一部分底仓
2. 回落后再买回来
3. 股数不变，成本降低
4. 卖飞了就卖飞了，别追高买回来

### 3.5 做T的铁律

- [ ] 做T仓位当天必须了结
- [ ] 做T是为了降成本，不是为了加仓
- [ ] 做错了及时止损
- [ ] 趋势坏了立刻停止做T，直接清仓
- [ ] 没把握就别做，宁可不做也别做错

## 四、龙头判断失误的降级处理

### 4.1 判断失误的信号

- [ ] 板块内有其他股票比它更强、涨得更高
- [ ] 总是跟涨不领涨，别人涨它才涨
- [ ] 涨停封不住，封板质量差
- [ ] 龙虎榜没有知名游资
- [ ] 市场讨论度低，辨识度不够

### 4.2 降级策略对照表

| 原分类 | 降级后 | 预期调整 | 仓位调整 | 策略调整 |
|---|---|---|---|---|
| 连板龙头型 | 强势反包型 | 从赚30%降到赚10–15% | 从6–8成降到3–5成 | 不赌连板，有利润就减 |
| 连板龙头型 | 波段震荡型 | 从赚30%降到赚5–10% | 从6–8成降到2–3成 | 做T为主，高抛低吸 |
| 强势反包型 | 波段震荡型 | 从赚15%降到赚5–8% | 从4–6成降到2–3成 | 快进快出，不格局 |
| 任何类型 | 平庸型 | 放弃 | 清仓 | 直接走人 |

### 4.3 什么时候必须认输清仓

- [ ] 跌破关键支撑位（20日均线/前期平台）
- [ ] 放量大跌，主力出逃
- [ ] 板块集体退潮
- [ ] 基本面出现利空
- [ ] 做T越做越亏
- [ ] 走势完全不符合预期

## 五、卖出条件清单

### 5.1 主动卖出（止盈）

- [ ] 放量滞涨：成交量创新高但股价不涨
- [ ] 炸板不回封：反复开板，尾盘封不住
- [ ] 高位长上影线：冲高回落，上影线 > 实体2倍
- [ ] 跌破5日均线：短线趋势破位
- [ ] 板块集体退潮：同板块多股大跌
- [ ] 情绪周期切换：从高潮转向退潮
- [ ] 达到预期盈利目标（因人而异）

### 5.2 被动卖出（止损）

- [ ] 买入次日低开 > 3% 且无反弹
- [ ] 跌破买入价 5%
- [ ] 走势完全不符合预期
- [ ] 出现重大利空消息
- [ ] 大盘系统性风险
