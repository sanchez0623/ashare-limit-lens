## 参考项目和本项目处理

参考项目 `D:/Sanchez/AI/WorkbuddyProjects/a-stock-momentum-trend/backend/app/core/datasource/lixinger_src.py` 的 `build_sw_map` 使用 `out.setdefault` 保留首次归属；它完成两次全量请求，但多归属时可能保留旧分类。本项目复用批量取数方式，并增加官方冲突核验，不复制这一处理。

本次真实网络验收：两次理杏仁 API 加一次官方 XLS 请求，输出 **4,611** 只股票，覆盖的一级／二级／三级行业为 **31／131／335**，三只冲突均已核验，来源依据通过 SQLite 暂存与发布后仍可读取。该次验收使用内存数据库，不改写正式历史归档或交易记录。行业数量按本项目范围内实际有股票的行业计算，与包含空行业的 511 条目录不同。

随后在独立临时 SQLite 和浏览器上点击“更新申万行业”，由实际 worker 完成真实网络更新，也得到上述数量；关闭并重开页面后显示成功结果，重复提交复用同一任务，不同范围提交返回 HTTP 409，取消后保留已发布快照。页面无脚本错误，来源说明在卡片内正常换行。行情接口在本次浏览器验收中使用空样本，避免触发无关行情抓取。正式数据库未改动，验收进程和临时数据库在结束时清理。`npm test` 640 项全部通过，`npm run build` 通过。
