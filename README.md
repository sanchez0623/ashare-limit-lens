# 涨停研究台

每日 A 股涨停复盘、个股评分、行业板块评分、事前快照、次日客观反馈与大模型审计。公开行情来源为东方财富；次日价格和交易日核验来自腾讯行情。

## 使用

运行 `npm ci`、`npm run build`。本地运行 `NODE_USE_ENV_PROXY=1 npm run dev`，本地 SQLite 数据只用于开发，生产持久化由 Sites D1 提供。运行 `npm test` 验证评分与反馈口径。

## 事前记录与反馈

- 页面在当天北京时间 15:05 后获取有效行情，自动调用 `/api/run-daily`，按服务端权重归档当天评分，同时检验上一交易日快照。
- 每个交易日只保存第一份原始评分；后续权重变化不覆盖历史。历史日期不补录为事前判断。
- 使用上证指数日期序列确认紧邻交易日。只有日期匹配、昨收与快照一致的个股才参与核验；除权等不可比情况单独剔除。
- 评分前 20% 作为固定观察组，次日计算开盘、收盘、盘中最低的观察收益、再次涨停比例、相对完整涨停样本超额以及 Spearman 秩相关。
- 客观反馈分至少要求十个有效样本、三个高分组有效样本、80% 覆盖率。这个规则分尚未收益校准，不能解释为可实现策略收益或上涨概率。
- 关闭页面时的无人值守更新需要已链接并验证可调用 `/api/run-daily` 的 Sites 定时任务。没有任务时只在访问页面或手动刷新时运行。

## 大模型配置

使用 Sites 服务端环境设置 `AI_API_KEY`（秘密）、`AI_BASE_URL` 和 `AI_MODEL`，重新部署使配置生效。

| 服务 | AI_BASE_URL | 模型示例 |
| --- | --- | --- |
| DeepSeek | https://api.deepseek.com/v1 | deepseek-chat |
| OpenAI | https://api.openai.com/v1 | 由用户的可用模型决定 |
| 通义 | https://dashscope.aliyuncs.com/compatible-mode/v1 | qwen-plus |

AI 审计只读冻结评分和已验证市场结果，输出系统得分、置信度、依据、不足和改进建议。不使用模拟输出，也不自动修改权重。未配置密钥或证据不足时不调用模型。

站点保持私有，写入接口依赖 Sites 的私有访问边界并校验 Origin。公开发布前必须添加相应的访问授权。

## 当前覆盖范围

公开涨停专题的覆盖范围由来源决定，目前按东方财富的沪深主板、创业板数据分析；不含 ST、科创板及连续一字新股。行业分组不是新闻题材分类。尚未包含逐笔、龙虎榜、公告文本与历史收益回测。
